# คู่มือผู้ใช้ Deposit OS (เบต้า 0.1.1)

ยินดีต้อนรับสู่ **Deposit OS** — ลินุกซ์ที่สร้างจากเคอร์เนลขึ้นมาใหม่
ใช้งานกับซอฟต์แวร์ Ubuntu ได้ ติดตั้งโปรแกรม Windows / Android /
Alpine / Fedora / Arch ได้ และมีหน้าจอภาษาไทยครบตั้งแต่บูต

---

## 1. เริ่มต้นอย่างไร

### 1.1 สร้างแฟลชไดรฟ์ติดตั้ง
```bash
sudo dd if=deposit-os.iso of=/dev/sdX bs=4M status=progress; sync
```
> เปลี่ยน `/dev/sdX` เป็นชื่อแฟลชของคุณ (ระวัง! ข้อมูลในแฟลชจะถูกลบ)

### 1.2 บูตเข้า Live USB
ปิดเครื่อง → เปิดแล้วกดปุ่มเมนูบูต (`F12`, `F9`, `Esc` แล้วแต่ยี่ห้อ)
→ เลือกแฟลช USB → จะเข้าสู่หน้าจอเดสก์ท็อปทันที (โหมด Live ไม่ต้องล็อกอิน)

### 1.3 ติดตั้งลงฮาร์ดดิสก์
- ดับเบิลคลิกไอคอน **Install Deposit OS** บนเดสก์ท็อป
- เลือกดิสก์เป้าหมายจากรายการ (ระบบ**จะไม่ยอมลบดิสก์ที่กำลังรันอยู่**)
- พิมพ์คำว่า `yes` เพื่อยืนยัน → รอจนเสร็จ → รีสตาร์ท
- ครั้งแรกที่ล็อกอิน ระบบจะ**บังคับตั้งรหัสผ่านใหม่** (รหัสเริ่มต้นสุ่มจากโรงงาน)

## 2. หน้าจอและการใช้งานประจำวัน

| สิ่งที่อยากทำ | วิธี |
|---|---|
| เมนูโปรแกรมด่วน | กด `Super+Q` (ปุ่ม Windows + Q) |
| เปิด Settings | ไอคอนเฟือง หรือเมนูด่วน → Settings |
| ปรับความสว่าง/เสียง | เมนูด่วน หรือ Settings |
| เปิด/ปิด Wi-Fi, โหมดเครื่องบิน | เมนูด่วน → Airplane |
| โหมด Turbo (เร่งเครื่อง) | เมนูด่วน → Turbo |

## 3. ติดตั้งโปรแกรม — รองรับ "ทุกโลก"

### 3.1 โปรแกรม Ubuntu (.deb) — ตัวหลัก
```bash
aqa install <URL>          # สแกนลิงก์ แสดงรายการให้เลือกติดตั้ง
sudo apt install <ชื่อ>    # วิธีปกติแบบ Ubuntu
```
- ไฟล์ `.deb` จากเว็บภายนอก **ต้องมี checksum**: ต่อท้าย URL ด้วย `#sha256=<ค่า>`

### 3.2 โปรแกรม Windows (.exe / .msi)
- **ดับเบิลคลิกไฟล์ได้เลย** — ระบบจะแสดงขนาด+ลายนิ้วมือ SHA256 ถามยืนยันครั้งเดียว
- ทุกโปรแกรมรันใน **กล่องทราย (sandbox)** และเป็นสิทธิ์ผู้ใช้ ไม่ใช่ root
- ถ้าถูกปฏิเสธ (REFUSED): ตรวจสอบไฟล์ปลอดภัยแล้ว อนุญาตด้วย
  ```bash
  echo <hash> >> ~/.config/deposit/win-hash-whitelist
  ```
- อยากได้หน้าจอแบบ Windows? `deposit-winmode on` (ปุ่ม Start + ทาสก์บาร์)

### 3.3 แอป Android (.apk)
- ดับเบิลคลิก `.apk` → ระบบเปิดคอนเทนเนอร์ Waydroid ให้เอง (ถ้ายังไม่เปิด)
- ติดตั้งครั้งแรก:  `sudo waydroid init`
- หรือเสียบสาย USB ไปที่มือถือ Android แล้วให้ระบบ sideload ผ่าน adb

### 3.4 แพ็กเกจ Alpine (.apk แบบ Alpine Linux)
- ดับเบิลคลิก → ติดตั้งลงโฟลเดอร์แยก `~/.deposit/alpine`
- เรียกใช้แอป: `deposit-apk run <ชื่อ>` · ดูรายการ: `deposit-apk list`

### 3.5 แพ็กเกจ Fedora/RHEL (.rpm) และ Arch (.pkg.tar.zst)
```bash
deposit-pkg app.rpm            # แตกไฟล์ลง ~/.deposit/rpm
deposit-pkg program.pkg.tar.zst
deposit-pkg run rpm <คำสั่ง>   # เรียกใช้งาน
```
> หมายเหตุ: สองฟอร์แมตนี้**ไม่แก้ dependency ให้** — เหมาะกับเครื่องมือเดี่ยว

## 4. อัปเดตระบบ
- เปิด **Settings → Updates** หรือ `deposit-updater`
- กดปุ่มเดียว: ตรวจ apt + แอป AQA พร้อมกัน

## 5. ภาษาไทย
- ฟอนต์ไทยและ `th_TH` ติดตั้งมาแล้ว
- พิมพ์ไทย: กด `Super+Space` สลับ IBus ↔ อังกฤษ

## 6. ความปลอดภัย
- AppArmor + ClamAV (`deposit-av`) + ไฟร์วอลล์ ufw (Settings → Security)
- แพ็กเกจ .mlpds ตรวจ GPG ทุกไฟล์ / .deb ภายนอกบังคับ checksum
- ไม่มีการล็อกอินอัตโนมัติในระบบที่ติดตั้งแล้ว (ช่องทาง liveboot เท่านั้น)

## 7. แก้ปัญหาเบื้องต้น

| อาการ | ทางแก้ |
|---|---|
| จอค้างหลังติดตั้ง | บูตแล้วเลือก recovery จาก GRUB, รัน `deposit-compat check <โปรแกรม>` |
| เสียงไม่ออก | เช็ค `pavucontrol` → Configuration → เลือกโปรไฟล์ |
| Wi-Fi ไม่ขึ้น | ลอง `rfkill unblock all` แล้วรอ 10 วิ |
| แอป jammy/focal ไม่ยอมรัน | `deposit-compat check ./app` ดู library ที่ขาด |
| Wine ถูกปฏิเสธ | ดู §3.2 — เติม hash เข้า whitelist |

## 8. ข้อจำกัดที่ควรรู้ (ตรงไปตรงมา)
- เคอร์เนลยัง**ไม่เคยทดสอบกับฮาร์ดแวร์จริงครบทุกรุ่น** — ถ้าเจอบั๊ก
  แจ้งได้ที่ GitHub Issues พร้อม `lspci -k` และรุ่นเครื่อง
- ARM64 รองรับบูต UEFI แล้ว (QEMU ผ่านทุกครั้ง) แต่ยังไม่เคยทดสอบ
  กับโน้ตบุ๊ก ARM จริง
- .rpm/.pkg.tar.zst ไม่แก้ dependency ให้ (อ่าน §3.5)
